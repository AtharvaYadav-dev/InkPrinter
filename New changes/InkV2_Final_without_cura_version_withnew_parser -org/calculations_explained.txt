Ye file explain karti hai ki main.py mein SYRINGE_SCALE, Purging aur File ki Length ka calculation kaise hota hai. Bahut aasan bhasha (Hinglish) mein samajhne ke liye:

---------------------------------------------------------
1. SYRINGE_SCALE ki Calculation (Scale kaise kaam karta hai)
---------------------------------------------------------
Code mein syringe motor kitna ghumega, iska calculation do steps mein hota hai:

- Pehla Step: Machine X aur Y axis par kitna physical distance travel kar rahi hai, usko ek "simulated extruder (E)" value mein convert kiya jata hai. Ek formula lagaya jata hai taaki distance ko chota kiya ja sake:
  `simulated_e = distance * 0.03326`
  (Ye 0.03326 ek constant hai jo (Line Width * Layer Height) / Filament Area se milta hai).

- Dusra Step: Is `simulated_e` ko aapke tune kiye hue `syringe_scale` (jiska default value 0.0089 set hai) se multiply karke final distance nikala jata hai:
  `actual_distance = simulated_e * self.syringe_scale`


---------------------------------------------------------
2. Purge karte waqt kya process hota hai (Operation ke dauran)
---------------------------------------------------------
Jab bhi code mein `G1` (linear move/extrusion move) command aati hai, aur uski distance > 0.000001 hoti hai, tab ye purging logic chalata hai:

1. Sabse pehle, Pythagoras theorem (`math.hypot`) ka use karke naye X aur Y coordinates se straight-line distance calculate hoti hai.
2. Us distance ko upar bataye gaye step se `simulated_e` aur fir `actual_distance` mein convert kiya jata hai.
3. Fir ek command string banayi jati hai: `"PURGE {actual_distance}"`. Jaise agar distance 0.5 hai to command banegi "PURGE 0.500000".
4. Aakhir mein, ye PURGE command `_send_to_blackpill()` function ke jariye Blackpill microcontroller (jo syringe motor ko control karta hai) ko bhej di jati hai.


---------------------------------------------------------
3. File ki "Total Length" ki Calculation (Kitni badi file hai)
---------------------------------------------------------
Yahan "Total Length" ka matlab file ka size (MB/KB) ya filament ki lambaai nahi hai. Iska seedha sa matlab hai ki **G-code mein total kitni lines (instructions) hain**.

Code ek `filtered_gcode` naam ki list banata hai jisme saari useful G-code lines hoti hain. File ki length pata karne ke liye bas us list ki length nikal li jati hai:
`total = len(self.filtered_gcode)`

Jab machine print kar rahi hoti hai, to progress (kitne % kaam hua) nikalne ke liye wo current line number (`self.pgm_index`) ko is total lines se compare karta hai.
`self.getProgress(self.pgm_index, len(self.filtered_gcode))`
Kyunki usko pata hota hai ki total kitni lines hain, to wo easily index/total karke progress bar update kar deta hai.
